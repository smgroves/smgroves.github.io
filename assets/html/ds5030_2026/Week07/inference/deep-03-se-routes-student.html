The map: where the unknown F gets replaced

Every standard error is the SD of an estimator's sampling distribution, and that SD depends on the unknown population \(F\). CASI §2.1 lists the devices for getting around this. The useful way to compare them is to ask when each one swaps \(F\) for something computable.

Plug-in and the ECDF

The empirical CDF \(\hat F_n\) is the sample treated as a population: probability \(1/n\) on each point. Every plug-in estimate is "compute the population quantity, but on \(\hat F_n\)." Glivenko–Cantelli says \(\hat F_n\) converges to \(F\) uniformly; DKW says how fast, with a band of half-width \(\epsilon_n = \sqrt{\log(2/\alpha)/(2n)}\).

The ECDF and its DKW band

Draw \(n\) car prices at random from the 92 (or type your own data). The step function is \(\hat F_n\); the shaded band is the \(1-\alpha\) DKW band; the smooth line is the "true" CDF (all 92 cars). Readouts are plug-in estimates.

Linear functionals (\(\int r\,dF\)) are averages of \(r(x_i)\), so their SE is the SD of the \(r(x_i)\) over \(\sqrt n\). Everything else needs a delta method or a bootstrap.

Taylor series

Covered in depth on page 2. The one-line summary: a smooth function of an average wobbles by the slope times the average's wobble. CASI's historical point is that before computers, every new statistic needed its own Taylor expansion; the SE of a correlation coefficient takes a page of fourth moments (CASI (10.10)), and the jackknife and bootstrap made that expertise unnecessary.

Work it by hand · SE of a ratio of means

Patch data style (AoS Ex 8.7): \(\hat\theta = \bar Y/\bar Z\). Delta method with two variables, \(g(y, z) = y/z\), gradient \((1/z, -y/z^2)\):

$$\widehat{\text{se}}^2(\hat\theta) \approx \frac{1}{\bar z^2}\Big(\widehat{\text{se}}^2(\bar y) - 2\hat\theta\,\widehat{\text{cov}}(\bar y, \bar z) + \hat\theta^2\,\widehat{\text{se}}^2(\bar z)\Big).$$

Tiny numbers: \(\bar y = 2\), \(\bar z = 4\), so \(\hat\theta = 0.5\); with \(\widehat{\text{se}}(\bar y) = 0.4\), \(\widehat{\text{se}}(\bar z) = 0.8\), and independent \(\bar y, \bar z\): \(\widehat{\text{se}}^2 = \frac{1}{16}(0.16 + 0.25 \times 0.64) = \frac{0.32}{16} = 0.02\), so \(\widehat{\text{se}} = 0.14\). AoS uses the bootstrap instead (0.105 on the real data) precisely to avoid this algebra.

Fisher information

For a parametric model, the MLE's SE comes from the curvature of the log-likelihood at its peak: sharp peak, small SE. The widget shows a Bernoulli log-likelihood. As \(n\) grows with the same success rate, the curve gets sharper and the SE shrinks like \(1/\sqrt n\).

Curvature is information

\(k\) successes in \(n\) trials. The solid curve is \(\ell(p) - \ell(\hat p)\); the dashed curve is the quadratic with the same curvature, \(-(p - \hat p)^2/(2\,\widehat{\text{se}}^2)\). The horizontal line at −1.92 crosses the curves near \(\hat p \pm 1.96\,\widehat{\text{se}}\): the Wald interval (dashed) and the likelihood interval (solid).

Work it by hand · three Fisher SEs
  • Bernoulli \(\{1, 0, 1, 1, 0\}\): \(\ell(p) = 3\log p + 2\log(1-p)\); \(\ell'' = -3/p^2 - 2/(1-p)^2\), at \(\hat p = 0.6\): \(-8.33 - 12.5 = -20.8\). \(\widehat{\text{se}} = 1/\sqrt{20.8} = 0.22\), which equals \(\sqrt{0.6 \times 0.4/5}\).
  • Poisson \(\{2, 4, 5, 6, 8\}\): \(\ell'' = -25/\lambda^2 = -1\) at \(\hat\lambda = 5\); \(\widehat{\text{se}} = 1\).
  • Exponential \(\{1, 2, 3\}\): \(\ell(\lambda) = 3\log\lambda - 6\lambda\); \(\hat\lambda = 3/6 = 0.5\); \(\ell'' = -3/\lambda^2 = -12\); \(\widehat{\text{se}} = 1/\sqrt{12} = 0.29\) (= \(\hat\lambda/\sqrt n\)).

The bootstrap

Resample, recompute, repeat

Click "1 resample" to see a single bootstrap sample (repeated points are stacked; missing ones are hollow). "1,000 resamples" builds the bootstrap distribution of the chosen statistic. The SD of that histogram is the bootstrap SE.

Try the maximum: the bootstrap distribution piles up on the largest data value and can never exceed it. That's the bootstrap's known failure for extreme statistics.

Work it by hand · the ideal bootstrap of {1, 3, 5}

Ten distinct resamples (probabilities out of 27): means 1, 3, 5 (1 each); 5/3, 7/3, 7/3, 11/3, 11/3, 13/3 (3 each); 3 (6). Bootstrap variance of the mean \(= 8/9\), SE \(= 0.94 = \hat\sigma/\sqrt n\). Medians: 1 w.p. 7/27, 3 w.p. 13/27, 5 w.p. 7/27, SE \(= \sqrt{56/27} = 1.44\). Set the widget to {1, 3, 5} and run 1,000 resamples: it should land near 0.94 and 1.44.

Story proof · how much does finite B matter?

With \(B\) resamples the bootstrap SE is itself an SD estimated from \(B\) draws, so its own relative noise is about \(1/\sqrt{2(B-1)}\) (page 4's formula, applied to the simulation). \(B = 200\) gives 5%, \(B = 1000\) gives 2%. Compare that with the statistical uncertainty in the SE from having only \(n\) data points (11% for the 92 cars). Past a few hundred resamples, more \(B\) buys almost nothing.

The jackknife

Leave one out

Each dot is the statistic recomputed with one point removed. The jackknife SE is their SD (divisor \(n\)) multiplied by \(\sqrt{n-1}\), because leave-one-out values are packed \(n-1\) times too close together. Compare with the bootstrap SE for the same data.

Work it by hand · jackknife of the mean and of the median

Mean of {2, 4, 5, 6, 8}: leave-one-out means 5.75, 5.25, 5, 4.75, 4.25; squared deviations sum 1.25; \(\frac45 \times 1.25 = 1\); SE 1 \(= s/\sqrt n\).

Median of {1, 2, 3, 4, 5}: leave-one-out medians 3.5, 3.5, 3, 2.5, 2.5; squared deviations sum 1.0; \(\frac45 \times 1.0 = 0.8\); SE 0.89. Only three distinct values: the median jumps from one data point to the next as points are removed, which is the non-smoothness that breaks the jackknife on larger samples (car prices: jackknife 1.43 vs bootstrap 0.75).

Pivots

A pivot's distribution doesn't depend on unknown parameters, so no plugging in is needed. The t-statistic is the classic: \(\sqrt n(\bar X - \mu)/S \sim t_{n-1}\) for normal data whatever \(\sigma\) is. Others: \((n-1)S^2/\sigma^2 \sim \chi^2_{n-1}\) (gives an exact interval for \(\sigma^2\)); for exponential data, \(2\lambda\sum X_i \sim \chi^2_{2n}\).

Work it by hand · an exact interval for σ² from a pivot

Toy data, \(s^2 = 5\), \(n = 5\). \(4s^2/\sigma^2 = 20/\sigma^2 \sim \chi^2_4\), whose 2.5% and 97.5% points are 0.484 and 11.14. So \(0.484 \le 20/\sigma^2 \le 11.14\), i.e. \(1.80 \le \sigma^2 \le 41.3\). A 95% interval for the variance runs over a factor of 23: five points say almost nothing about spread.

Questions

Think about itThe bootstrap SE of the mean for the toy data comes out near 0.89, not 1. Which is right?

Both are estimates of the same thing. The bootstrap is a plug-in method, so it reproduces \(\hat\sigma/\sqrt n\) with divisor \(n\): \(2/\sqrt5 = 0.89\). The textbook \(s/\sqrt n = 1\) uses divisor \(n - 1\). At \(n = 5\) the difference is 11%; at \(n = 92\) it's 0.5%.

Think about itIn the Fisher widget, why does the Wald interval sometimes go below 0 when \(\hat p\) is near 0, but the likelihood interval doesn't?

The Wald interval is symmetric by construction (\(\hat p \pm 1.96\,\widehat{\text{se}}\)), but the likelihood is lopsided near the boundary. The quadratic approximation is the delta-method idea applied to the log-likelihood, and it fails where the curve isn't close to a parabola: small \(n\) or \(p\) near 0 or 1.

Check your understandingWhy must the two-sample bootstrap resample each group separately?

Pooling and resampling 72 patients would make the group sizes random (sometimes 30 AML, sometimes 20), adding variability the real study didn't have, since the design fixed the group sizes. Resample within each group to mimic the design (CASI §10.3).
