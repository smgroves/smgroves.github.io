SCLC Subtype Map

Sarah Groves · SCLC research

Since 1985, SCLC has been split into classic/variant, NE/non-NE, A/N/P/Y, A/N/P/I, archetypes, clusters and NMF groups. Each box is a label from one paper. Lines show which of the current states (colored circles) it corresponds to: a double line means the same state, a single line means partial overlap. Click anything for details, including what kind of data (human tumors, cell lines, mouse models, organoids) each state was found in. For example, ISL1 is high in SCLC-A and low in SCLC-A2 (Wooten 2019), and the later "ISL1+ subtype" (Shields 2026) maps onto SCLC-A.
