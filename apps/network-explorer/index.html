How is the first file structured?

Level columns, top to bottom in file order. Other columns become attributes of the deepest node; numbers are summed up the tree.

Compare number columns (optional)

For example, expression in each subtype. Adds a “Highest in” tab plus a Low / Medium / High tab for each column you tick.
Accepted formats

Edge list. Extra columns become connection attributes.

source,target,type,weekly_hours
Ava Chen,Ben Okafor,Collaborates,6
Ben Okafor,Isla Reyes,Reports to,1

Node attributes (optional second file). Text columns with up to 30 values become tabs.

id,department,office,tenure
Ava Chen,Engineering,Seattle,3.5
Ben Okafor,Product,Boston,6.1

Parent–child rows. Other columns describe the node in that row. Leave parent blank for a root.

parent,node,department,headcount
,CEO,Leadership,1
CEO,CTO,Engineering,40
CEO,CFO,Finance,12

Wide hierarchy. Each row is a path; numbers are summed upward (illustrative values).
